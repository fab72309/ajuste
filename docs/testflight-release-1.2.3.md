# AJUSTE 1.2.3 — notes de version

## Texte App Store Connect / TestFlight

Cette mise à jour rend les associations plus faciles à comprendre :

- les détails statistiques sont organisés en cartes lisibles, sans balayage
  horizontal obligatoire ;
- les coefficients sont affichés avec une notation décimale française ;
- VoiceOver décrit désormais le sens et l’échelle du coefficient de Pearson.

Les associations restent exploratoires : elles ne constituent ni un diagnostic,
ni une preuve de causalité, ni un conseil médical.

## Texte court pour la vidéo YouTube

AJUSTE 1.2.3 clarifie la lecture des associations : les statistiques sont
présentées en cartes, les décimales sont localisées et VoiceOver explique mieux
le sens du coefficient de Pearson.
